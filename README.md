# Kanto Reloaded

An overhaul for KIF Beta. Most features can be switched on or off, and its settings live in KIF Settings.

## Installing

1. Install KIF Beta.
2. Download this repository and rename its folder to `KantoReloaded`.
3. Put it in KIF Beta's `Mods` folder, so the path is `Mods\KantoReloaded\mod.json`.
4. Start the game. Kanto Reloaded's settings are in its own section of KIF Settings.

Kanto Reloaded keeps its settings and logs in its own folder (`Settings`, `Logging`). Bug reports go in `Logging\Bug Reports`. Only things that belong to a save, like backups and notes, go beside your saves.

## Reporting a Bug

Make a Bug Report in the game and send the file in Kanto Reloaded's Discord. The report has everything needed to fix the bug, and your Windows user name is taken out.
